# Code of Conduct

Hinata aims to be a welcoming open-source project.

## Expected behavior

Contributors and participants should:

- be respectful and constructive
- discuss technical disagreements without personal attacks
- give useful feedback and accept reasonable feedback in return
- respect privacy and avoid publishing another person's sensitive information
- keep issues and pull requests relevant to the project

## Unacceptable behavior

Harassment, threats, discrimination, deliberate disruption, doxxing, spam, and abusive conduct are not welcome.

## Enforcement

Project maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the project and its community.

If a situation involves a security vulnerability, use the process in [SECURITY.md](SECURITY.md) instead of posting sensitive details publicly.
