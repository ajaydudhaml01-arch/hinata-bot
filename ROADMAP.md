# Hinata Roadmap

This roadmap is directional rather than a promise of dates.

## Near term

- expand automated tests for commands, handlers, and permission checks
- improve error handling and user-facing failure messages
- make more moderation thresholds configurable
- improve documentation and self-hosting examples
- add better validation for `config.json`

## Medium term

- per-guild configuration instead of a single server-oriented config
- pluggable persistence layer
- SQLite adapter for easy self-hosting
- database option for larger deployments
- migration utilities for local JSON data
- improved logging and observability

## Longer term

- optional web dashboard
- plugin/module API for community extensions
- localization support
- richer moderation rule engine
- documented deployment recipes for common hosts

Ideas and contributions are welcome through GitHub issues and pull requests.
