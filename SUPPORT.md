# Support

For help using Hinata:

1. Read the [README](README.md), especially Quick start and Configuration.
2. Search existing GitHub issues.
3. If you found a reproducible bug, open a bug report.
4. If you want a new capability, open a feature request.

When asking for help, include:

- Node.js version (`node --version`)
- npm version (`npm --version`)
- operating system / hosting platform
- relevant error message
- steps to reproduce

Do **not** include your Discord token, `.env`, private credentials, or sensitive server data.
